OAuth 2.0 PKCE Demo

A sample OAuth 2.0 authorization code flow with PKCE. Every network call runs in the browser — open DevTools to watch the full flow.

What this demonstrates

  • PKCE challenge generation (code_verifier → SHA-256 → base64url)
  • Authorization redirect with state (CSRF protection)
  • Authorization code exchange for access token
  • Authenticated userinfo request
