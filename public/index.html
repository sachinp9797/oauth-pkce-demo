🔐 Xola OAuth Sample App

This is a sample OAuth2 client demonstrating the authorization code flow with PKCE.

What does this app do?

  • Initiates an OAuth authorization request to Xola
  • Generates PKCE challenge values in-browser
  • Handles the redirect callback in the browser
  • Exchanges authorization code for an access token
  • Fetches and displays authenticated user information
