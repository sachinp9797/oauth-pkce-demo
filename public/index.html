🔐 Xola OAuth Sample App

This is a sample OAuth2 client demonstrating the authorization code flow with PKCE.

What does this app do?

  • Initiates an OAuth authorization request to Xola
  • Generates a PKCE challenge (code_challenge + code_verifier)
  • Handles the redirect callback from Xola
  • Exchanges the authorization code for an access token
  • Fetches and displays authenticated user information

Prerequisites

Before using this app, you need to:

  1. Have a running Xola instance with OAuth endpoints
  2. Register an OAuth client: 
    curl -X POST http://localhost/api/oauth/register \
  -H 'Content-Type: application/json' \
  -d '{
    "client_name": "Sample App",
    "redirect_uris": ["http://localhost:8080/callback"],
    "grant_types": ["authorization_code", "refresh_token"]
  }'
  3. Copy the client_id and client_secret to your .env file
